# 执行与状态设计

所有入口先尝试连接指定数据目录中记录的 loopback 服务；连接不到才创建本地引擎。引擎对 `engine.lock` 持有独占文件锁，防止同一数据目录出现两个调度器。原生窗口和浏览器工作台通过 HTTP API，TUI/CLI 可直接使用引擎或通过 RemoteRuntime 连接。

任务状态：`queued → running → waiting_approval → running → completed`，失败进入 `failed`，取消进入 `cancelled`，服务重启后原活动任务进入 `interrupted`。事件独立保存工具开始、参数、具体审批计划、批准/拒绝、结果与错误。批准只存在于活动引擎内存中，重启不会恢复批准或重放动作。

默认单执行线程使文件修改和会话历史保持提交顺序。消息持久化保存 parent_id 和书签 label，会话保存 active_leaf；显示与模型上下文沿当前节点的祖先路径读取，其他分支保留在同一会话中。任务的历史上下文截至当前提交，不包含之后排队的问题；回答插入对应用户消息之后，再连接排队的下一轮，避免快速连续提交时回答错位。

TUI `/tree` 使用独立导航器提供搜索、折叠、筛选和书签。选择用户消息时切换到其父节点并预填原文，选择助手回复时切换到该回复。切换会话分支拒绝该会话有活动任务的情况。HTTP /api/tree、/api/tree-navigate、/api/tree-label 与 RemoteRuntime 共享相同行为；桌面消息刷新也检测 active_leaf 的变化。旧数据库首次打开时保留原消息内容与 ID，按原任务顺序补齐线性父链。

主控模型可以返回多个结构化工具调用。引擎依据能力目录执行，最多八次模型/工具循环；工具输入与输出保留在审计事件中，模型收到结果后继续规划或总结。快捷入口与部分确定性指令直接调用相同工具，故本地操作无需支付模型调用成本。没有调用旧版无授权目录约束的 Agent.handle 路径。

能力执行器解析路径，检查授权根和凭据排除。变更类工具先生成计划；整理使用大小与纳秒修改时间快照，批准后预检整个批次，以 hard-link + unlink 实现同一文件系统内不覆盖目标的移动，异常尝试逆序回滚。这不是跨设备移动，也不能保证在并发外部写入或回滚目标冲突下完全恢复；事件中的已移动路径用于追踪。

定时器每秒检查到期工作流，活动任务未结束时不重复提交。重启时不会补跑每一个错过的周期。存储时间为 Unix 时间戳，桌面界面按用户机器时区显示。

HTTP 只绑定 loopback，随机访问令牌经 URL fragment 传入前端 sessionStorage，不进入请求 URL、HTTP 日志或 Referer。接口需要 X-Marvis-Token，校验 Host/Origin，并设置 CSP。进程间连接信息以 0600 文件保存。没有远程认证与 TLS，不能对公网暴露。

本地模式用独立的 loopback 模型配置，禁用网页/网络搜索/联网浏览器打开；模型请求拒绝重定向。效率模式可能将工具取得的文件内容作为模型上下文发送至配置端点，必须由使用者选择可信端点。
