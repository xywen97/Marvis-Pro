# Marvis 功能对照与交付边界

依据 2026-10-11 可访问的 [腾讯 Marvis 官网](https://marvis.qq.com/) 和 [腾讯云产品说明](https://developer.cloud.tencent.com.cn/techpedia/2612)，整理产品功能范围。官网描述不能证明其内部算法实现；本项目采用独立实现，不使用腾讯内部接口或视觉素材。

| 功能领域 | 当前实际实现 | 状态 / 仍需实现 |
|---|---|---|
| macOS App | WKWebView 原生窗口、工作台、会话、任务、知识库、自动化、设置 | 已实现；视觉点击验收尚未完成；开发 .app 可双击，独立分发/签名未完成 |
| TUI | curses 全屏、中文输入、五个页面、快捷键、任务批准与取消、命令工具 | 已实现并做实际交互验证 |
| 主控与专项 Agent | 一个模型进行多步结构化工具编排，五类工具按领域执行并记录状态 | 已实现；独立 Agent 上下文、并行推理与真正虚拟办公室未实现 |
| 文件搜索 | 按文件名、文本内容，限定目录，支持 UTF-8 文本与可选文档解析 | 已实现；自然语言复杂查询依赖模型；向量检索、时间组合筛选未实现 |
| 文件整理 | 分类预览、确认后移动、冲突/变动检查、失败尝试回滚 | 已实现；按主题语义整理、历史撤销、批量重命名未实现 |
| 去重 / 清理 | SHA256 查找重复文件 | 查重已实现；缓存清理、删除入废纸篓未实现 |
| AI 文档库 | 本地 SQLite 内容索引、文件名/文本匹配、读取文档 | 已实现；向量与语义标签、增量监视未实现 |
| AI 图库 | 图片文件名、类型、大小和时间索引，OCR 工具入口 | 部分实现；人像、地点、主题识别和语义检索未实现 |
| OCR | 本机 tesseract `chi_sim+eng` 调用 | 已实现接口；需用户安装引擎及语言包，未在此机验收 |
| 文档深度理解 | File Read + 模型多步分析，可请求写出 Markdown/TXT | 已实现基础链路；合同/运营分析依赖模型，未验证业务质量 |
| 文档格式转换 | CSV→JSON/Markdown、JSON→CSV、PDF/Word/Excel 等内容→TXT | 已实现；Office/PDF 任意互转、版式保真未实现 |
| 图表 / PPT / 专业文档生成 | 可生成文本文件内容 | 原生图表、DOCX/XLSX/PPTX/PDF 生成未实现 |
| 系统理解 | 系统架构、主机、CPU 数、磁盘、内存、进程、电池 | 已实现 macOS 只读查询 |
| 系统设置 / 网络修复 | 不修改系统 | 未实现；需要逐项定义 macOS 适配与审批执行器 |
| 软件管理 | 已安装应用发现、确认后启动 | 部分实现；应用内 GUI 操作、安装、卸载与退出未实现 |
| 浏览器操作 | 公开 HTTP(S) 网页内容抓取，确认后打开系统浏览器 | 部分实现；登录态、视觉浏览、点击/填写与截图未实现 |
| 网页搜索 | DuckDuckGo HTML 搜索，返回来源链接 | 已实现接口；依赖外部服务，可能限流，无伪造结果；未做实际联网验收 |
| 自动化 / 情报监控 | 间隔工作流、模板、运行/暂停/恢复/删除、上次任务跟踪 | 定时执行已实现；页面差异监控、系统通知、复杂工作流 DAG 未实现 |
| 效率 / 本地模式 | 可配置 OpenAI 兼容模型；本地固定 Ollama；本地模式拒绝网络工具 | 实现并测试网络阻断；本地模型下载与真实推理质量未验证 |
| 远程手机控制 | 无 | 用户当前优先 macOS App + TUI，未实现跨端配对、屏幕流、远程输入 |
| 权限与审计 | 文件授权目录、凭据排除、具体操作批准、事件记录、任务取消、本机 API 令牌 | 已实现；不是操作系统级沙箱，非防篡改审计；无公网服务能力 |
| 游戏 / 追星 / 生活场景 | 通用模型对话和网页工具可提供信息类辅助 | 不提供自动签到、游戏操控、支付或账号接管 |

## 后续实现顺序

1. **本机执行闭环**：文件回收与撤销、受控应用退出/设置、增量索引、图表与 Office 输出；用真实样本做端到端验收。
2. **浏览器与应用操作**：隔离浏览器配置、页面定位/截图/填写、macOS 辅助功能执行器、可接管动作流程；每种动作设定边界和实际验收用例。
3. **图片与知识理解**：本地 OCR 默认引擎、视觉模型、图片主题标签、嵌入检索；明确本地模式的数据流。
4. **持续运行与发布**：launchd 后台引擎、桌面通知、更新机制、独立 .app 构建、签名与公证。
5. **更多产品场景**：具备上述执行器后再实现监控、办公和生活场景模板；只有逐项验收通过，才能称为完整复现。
