# 同一会话内的执行树

`/tree` 或 `/t` 打开当前 session 的完整执行步骤树。移动和搜索本身不会改变上下文；按 Enter 才切换当前位置。原分支不会删除，也不会生成新的 session。

| 选中的步骤 | 当前节点与输入框 | 下一次请求 |
| --- | --- | --- |
| user | 当前节点退到该 user 的父节点，原文填入编辑器 | 修改并发送后，创建一个新的 user 分支 |
| thinking / 公开行动说明 | 当前节点设为这条说明，编辑器清空 | 祖先路径包含这条说明，排除后面的工具和回答 |
| tool call | 当前节点设为该调用，编辑器清空 | 保留调用结构，没有返回结果的调用明确标记缺少结果 |
| tool result | 当前节点设为该结果，编辑器清空 | 保留此前调用和真实结果，排除后面的步骤 |
| assistant / 最终回答 | 当前节点设为该回答，编辑器清空 | 从这条回答继续追问 |
| system / 会话起点 | 当前节点为空，编辑器清空 | 新问题成为同一会话中的根分支 |

模型上下文包含当前分支的祖先节点和本次输入，其他分支不会混入。跳转和工具调用的历史展示不执行旧工具，不撤销已完成的文件操作。有排队、执行、待确认或收尾中的任务时，不允许切换位置。

## 键盘操作

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 选择相邻可见步骤 |
| Page Up / Page Down | 快速移动 |
| ← / → | 折叠、父节点、展开或进入子节点 |
| Enter | 直接切换，不生成摘要 |
| Ctrl+S | 生成离开的分支摘要，再切换；需要可用模型 |
| Esc | 返回编辑器，保留当前分支和原草稿 |
| 输入文字 | 多关键词搜索，要求每个关键词都匹配 |
| Ctrl+U | 清空搜索 |
| Ctrl+O | 默认、用户、书签、无工具、全部筛选 |
| 大写 L | 设置、修改或清除选中节点的书签 |

● 表示当前节点，• 表示当前路径。单一执行链保持紧凑；分叉处显示连接线与缩进，当前分支排在同级分支前面。完整记录和书签会持久化，旧会话自动从保存的工具事件补齐步骤。

输入 `/tree` 或 `/t` 后按回车即可进入步骤选择界面，无需节点 ID。模型生成的可选摘要只附在目标位置；失败时保持原位置，不更改旧分支。归档保留整棵树，删除对话时清理全部执行节点。

## 与 pi 规则的对应

pi 将 `/tree` 定义为当前会话内的跳转，区别于创建另一份会话的 `/fork`。用户消息回到父节点并预填编辑器，其他条目从选中位置继续，模型只接收活动分支。本项目遵循这些规则。[官方会话文档](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sessions.md)、[导航实现](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/agent-session.ts)。

pi 的 assistant 条目包含思考/文本/工具调用块。本项目按需求将公开行动说明、每个工具调用和每个工具结果拆成独立可选步骤；“thinking”对应已有的公开说明，不采集模型私有推理字段。系统起点是导航用的虚拟根，实际系统提示由当前配置构建。

pi 在接口转换时为没有返回结果的历史调用补充 `No result provided` 错误。本项目采用相同原则：只在发送给模型的接口投影中补齐缺失标记，不写成真实执行结果，也不执行旧调用。[官方上下文转换实现](https://github.com/earendil-works/pi/blob/main/packages/ai/src/api/transform-messages.ts)。

树节点筛选、搜索和紧凑分叉布局参考 [官方树选择器](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/modes/interactive/components/tree-selector.ts)。本项目沿用 curses 快捷键：Enter直接切换，Ctrl+S选择先摘要再切换。
